# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-10-09

### Added

- A sortable **Last Updated** column for public post type admin lists.
- Placement of the column directly after the core **Date** column.
- Modified date and time formatting that matches the core **Date** column.
- The last editor's display name on row hover, using WordPress row-action behavior.
- A permission-aware link from the editor's name to their WordPress profile.
- A fallback to the post author when WordPress has not recorded a last editor.
- PHPUnit coverage with Brain Monkey mocks for WordPress functions and hooks.
- Norwegian Bokmål translations for the plugin-owned admin strings.
